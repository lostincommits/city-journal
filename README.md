# city-journal
A personal collection of notes from places, buildings and streets that caught my attention.  Most entries were written while travelling or exploring new places.


# Project Notes

This repository is an old collection of files recovered from different
projects.

Some files were added at different times and some were moved during
cleanup.

There is no guarantee that the important information is in the first
file you open.

A few notes may look unrelated, but they were kept together for a
reason.

**If you want the complete picture, don't stop at the first useful
thing you find.**

Check the files. Check the history. Then connect what you find.
